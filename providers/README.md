# Provider Framework Links & Integrations (`providers/`)

This directory contains framework navigational links and top-level symlinks pointing to installed AI provider systems, CLI tools, and agent runtimes.

## Purpose

These links serve as single-source-of-truth pointers to synchronize prompt packs, active skill surfaces, and MCP servers across multiple AI coding tools without duplicating configuration files.
